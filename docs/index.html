Classical Arabic, counted exactly.

Bayt al-Hikma is a research program in four parts. Two parts count patterns in Classical Arabic texts. Two parts rebuild the mathematics of the House of Wisdom scholars in exact rational numbers.

Every count can be run again from the same pinned texts. Every failed test stays on the page.

01 // The four studiesTwo corpus tracks. Two lineage tracks.4/4 pass offline

Four studies, one ledger.

Each study ships code, a full report, tests and a JSON certificate. A certificate is a saved result file. The code must rebuild it byte for byte, or the check fails. Pure-Q means the arithmetic uses exact fractions. It never uses floating point numbers on the paths that decide pass or fail.

02 // A finding that reversedWindow W = 20. Lift over shuffle null.Ladder retracted

The ladder ran backwards.

The first count ranked word forms by raw cohesion. Roots looked strongest, then stems, then surface forms. That ranking was an artefact. Coarser units match more often by chance, so their baseline is higher.

Each layer was then compared with its own shuffled baseline. The order flipped. Surface forms now lead, and roots come last. A prose control, Kalila wa-Dimna, sits above the Quran stem value. The lift is a shared property of Classical Arabic prose. It belongs to no single text.

03 // Status of every claimWhat held, what failed, what stays open.

What held. What did not.

The program uses the falsafa habit in a strict form. Falsafa is the philosophy and science of the Islamic Golden Age. Its best known figures here are Ibn Sina (Avicenna) and Ibn Rushd (Averroes). They treated reason as a path to truth. This site keeps that habit and adds a modern rule: state the test before you trust the pattern, and keep the failures where readers can see them.
