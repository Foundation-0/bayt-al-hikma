Reproduce: run every check.

You need Git and Python 3. Nothing else. Two paths are offered because they prove different things. The live path recounts the Arabic texts. The offline path needs no network and says plainly that it did not.

Path A // Live recountRecommended. Downloads about 10 MB, once.live_corpus_recounted: true

Recount from the texts.

Step 1 prints the source, edition, licence, byte size and SHA-256 digest of each text without touching the network. Step 2 downloads each file and refuses it unless size and digest match the pin. Files land in ./corpora, which Git ignores. Step 3 recounts both corpus studies from those files, recomputes both lineage studies, runs all test suites and checks all 20 pinned files.

PASS in live mode means: all 9 texts on disk match their pins. Both corpus audits recomputed every count and every B = 250 null from the texts and matched their saved certificates byte for byte. Both lineage certifiers rebuilt every theorem and matched. All 4 test suites exited 0 under -I -O -B -W error. The flags mean: -I isolated mode (ignore environment), -O optimised (asserts stripped, so tests cannot hide behind them), -B no bytecode files, -W error warnings as errors.

Path B // Offline checkNo network. No downloads.live_corpus_recounted: false

Check without the corpus.

The lineage studies need no texts, so offline mode still rebuilds them in full. The corpus studies instead replay small pinned fixtures (saved example inputs with known answers) and read no corpus file at all. Run the verifier three ways. Output must be identical each time. That sameness is part of the check.

Read the banner. Offline PASS prints arabic_live_corpora_recounted=false. It proves the lineage arithmetic and the fixture logic. It does not prove a recount from the nine texts. Only Path A does that. Any summary that drops this line misstates the result.

What gets counted.

Four Quran-related files and five OpenITI controls. Controls matter: without other Classical Arabic prose and poetry beside the target text, shared language behaviour looks like a property of one book. Licences travel with the files and are printed by the manifest command. Digest prefixes below identify each pin. Full digests live in fetch_corpora.py.
