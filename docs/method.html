Method: reason, used with care.

This program reads old texts with new counting tools. That mix invites two errors: forcing modern ideas onto old words, and finding patterns that chance put there. The method exists to block both.

01 // FalsafaWhy a counting program opens with philosophy.

A way of seeing.

Falsafa, from the Greek word for philosophy, names the rational tradition of the Islamic Golden Age. Its best known figures in this program are Ibn Sina (Avicenna, 980 to 1037) and Ibn Rushd (Averroes, 1126 to 1198). Both appear in the lineage tables with verified constructions attached. Both held that reason and revelation are two paths to the same truth, and pursued science as part of religious life.

That stance shapes the work here in a practical way. Curiosity about pattern is welcome. Patterns below the surface are worth hunting. But a pattern earns belief only after it survives a fair test. Gratitude for the text and rigour toward claims about the text go together. Neither replaces the other.

The personal form of this stance lives on the belief page of the author site. This page states the research form: the same seeing, bound to counts anyone can rerun.

02 // Five rules in plain wordsAletheia v2.0.0, as used in this repository.

The rules

Rule 1 · Own terms first

Meet the text where it stands.

Read a classical source in its own categories before mapping it to modern ones. Wazn, rasm and root are the tradition's own units, so the corpus studies count those. Modern labels come second and must say what they add. In code this rule is OWN_TERMS_FIRST.

Rule 2 · Strongest fair restatement

Test the best version, not the weakest.

Before judging an idea, restate it in its strongest defensible form and test that. The mirror ring failed in its strong pointwise form. The softer inclusio form was then stated cleanly and tested on its own terms. It remains inconclusive. Weak versions are never used as easy targets. In code this is Law 2b, the transformational steelman.

Rule 3 · Exact arithmetic, stated nulls

Count in fractions. Shuffle 250 times.

Trust paths use exact rational numbers (pure-Q), never floating point approximations. Every statistical claim faces B = 250 deterministic shuffles with exact rank p-values: p = (1 + number of nulls at least as large) / 251. Families of tests pay a Holm-Bonferroni correction at alpha = 1/20. B = 250 is chosen so even a 12-test family can still pass: 12/251 = 0.0478, just under 0.05.

Rule 4 · Novelty default N0

Known until the full text says otherwise.

Every study here is tier N0. Classical philology, historical theorems and published editions are prior art. A higher tier (N1) needs a full-text prior art audit, not a hunch. Until that audit exists, the honest claim is replication and exact verification. In code this is Law 4.

Rule 5 · Zero numerology

No meaning from digit games.

Letter values, digit sums and code hunting are banned as evidence. A code function (enforce_zero_numerology_policy) rejects feature names carrying such labels. That filter is hygiene only. It checks names, not truth. Soundness rests on pre-registration, nulls and controls. In code this is Law 5.

04 // Locked protocolRules for any future confirmatory claim. Version 1.0.

Next time, decide first.

Exploration found the patterns above. Confirmation must work the other way round. The locked protocol requires all of the following before target data is inspected:

  • Fix hypotheses, units and window sizes in advance. Select roots by rule, not by hand: all multi-lemma roots in Leeds v0.4 with verse count from 20 to 300.
  • Use B = 250 deterministic shuffles with exact rank p-values. Single-shuffle nulls are prohibited for inference. Correct every family with Holm-Bonferroni and report the full family size, failures included.
  • Call odd and even splits split_half_internal_consistency. Never call them unseen or held-out. True held-out claims need external data the pipeline has not touched.
  • Require a morphologically form-tagged control corpus before any cross-corpus claim about wazn. The current program has none, and says so.
  • Keep novelty at N0 unless a full-text prior art audit supports more.

Author and verifier seats are separate in this program. The corpus studies were authored by continuum-bridge, the lineage studies by fractals-probe, and all four were checked by an independent verifier seat. External Aletheia tooling receipts (mutation testing, static checks) live in the Foundation-0/aletheia repository. They are reported as external receipts, not as results this repository reproduces on its own.

05 // How to read this siteDesign sources, stated once.

Three sources, one system.

The room comes from the belief page: deep ink green, gold, serif chapters set in Cormorant, body text in Outfit, and the six-circles geometry. The system comes from Eido, the design language of ML Weft: colour is set in OKLCH (a colour space where equal steps look equal) and turns with one hue number. Drag the hue control in the header. The whole palette follows, on every page, and the choice is remembered on your device. Hue is style only. It never encodes a finding.

The discipline comes from Foundation-0 research pages: numbered panels, evidence tags on every claim, numbers printed beside every figure, and digests you can copy and check. Each figure caption states what each visual channel counts. Bar length is lift. Timeline position is lifespan. The nine ring points count nine texts. Anything that carries no quantity, such as the slow rotation of the opening pattern, says so.
